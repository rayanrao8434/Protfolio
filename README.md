# Muhammad Rayan Rao Portfolio

A personal portfolio for machine learning, generative AI, and agentic automation projects. Built with React, Vite, Tailwind CSS, and Framer Motion.

## Sections

- Hero and profile
- About
- Projects
- Skills
- Achievements
- Contact

## Run Locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

## Checks

```bash
npm run lint
npm run build
```

## Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- ESLint
